# ArtScreen

Минимальная галерея классической живописи для LG webOS 6+ (включая LG C2).
После запуска картины показываются автоматически, без меню и рамок.

- Фон `#000000`, исходные пропорции, вся картина помещается на экране.
- Смена каждые 5 минут, перекрёстное затухание 1,6 секунды.
- Смещение в пределах ±12 пикселей раз в минуту; поля 30 пикселей сохраняют картину целиком.
- Постоянный кэш IndexedDB: до 100 МБ (100000000 байт) данных изображений, удаление давно использованных записей. Служебные данные браузера не входят в этот объём. При меньшей квоте приложение продолжает работать без записи новых файлов.
- При недоступности сети уже сохранённые картины доступны; не загружающиеся работы пропускаются. При первом запуске нужен интернет.
- Вправо / OK — следующая картина, влево — предыдущая в перемешанной подборке, Back — закрыть приложение.
- В фоне автоматическая смена приостанавливается.

## Сборка

Нужен Node.js 22.

```sh
cd artscreen
npm ci
npm test
npm run package
```

Пакет: `artscreen/build/org.artscreen.gallery_0.2.0_all.ipk`.
Установка через webOS Dev Manager или:

```sh
npx ares-install --device lgtv build/org.artscreen.gallery_0.2.0_all.ipk
npx ares-launch --device lgtv org.artscreen.gallery
```

## Каталог картин

`artscreen/src/art.json` содержит название, автора, URL изображения, страницу источника, размеры оригинала и статус лицензии. Данные получены непосредственно из Wikimedia Commons. В подборку допускаются JPEG-репродукции public domain/CC0 с оригиналом не меньше 3840×2160. Для загрузки запрашивается версия шириной 3840 пикселей. Сведения об источниках сохраняются в составе приложения в `artworks.json`.

Обновление: `cd artscreen && npm run catalog`. Сборщик не заменяет каталог, если не нашёл хотя бы одну подходящую работу каждого заданного художника. Автоматическая проверка метаданных не заменяет визуальную редактуру подборки.

**Разрешение:** webOS ограничивает графический слой веб-приложений 1920×1080. Исходники высокого разрешения не означают нативный вывод 4K. Для нативного 4K потребуется отдельный видеоконвейер или нативный рендерер. См. [документацию LG](https://webostv.developer.lge.com/develop/specifications/app-resolution).

## Releases и Homebrew Channel

Отправка в main запускает тесты и сборку с IPK-артефактом. Тег `v0.2.0` запускает публикацию GitHub Release: IPK, SHA256SUMS, icon.png, apps.json и манифест с SHA-256 пакета. Версии package.json, appinfo.json и тега должны совпадать.

В Homebrew Channel → настройки → добавить репозиторий:

```text
https://github.com/yaquake-dot-com/artscreen/releases/latest/download/apps.json
```

Публикация работает после отправки кода и тега в GitHub; приложение не требует root для ручного запуска.

## Проверка на телевизоре

Сборка на компьютере не проверяет поведение LG C2. На устройстве нужно проверить запуск, загрузку по HTTPS/CORS, сохранение кэша после перезапуска, работу без сети, пульт, переходы и возврат из фона.

Замена штатного скринсейвера пока не реализована. Это отдельная интеграция, зависящая от прошивки и доступа root; установка IPK не изменяет системный скринсейвер.

Инструменты webOS CLI имеют транзитивные зависимости с известными предупреждениями npm audit; они используются только при разработке и упаковке и не входят в IPK.
